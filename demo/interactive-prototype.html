Intended phone companion: background GPS recording, offline seasonal species data, speech-to-text, validated LLM parsing, run history, and separate eBird CSV + timestamped KML exports. The watch uses touch for map-point selection and physical buttons for reliable navigation.

Screen & data behavior

Selected species
Single SELECT: Add when the count is zero; Edit / Delete / History for an existing record.
Run management
Hold SELECT: save and leave the watch interface. Open a saved run later to continue or review.
Voice workflow
Hold UP to dictate. The phone interprets species, number, and whether to set or increment a count.
GPS map
Hold DOWN for a route schematic with blue sighting pins. Tap any pin to see species and time.
